# We Got Standing Desks

A program that writes one line about office life, a single joke about
standing desks, to `/output/entry.txt`, for the make.fun competition
[Make the AI Judge Laugh](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 82 characters, one line, inside the 1 to 200
character brief.

## The line

```
We got standing desks so we could stand more, and now we all sit on taller chairs.
```
